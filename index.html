life-ops

life-ops is a private, single-user tool that helps me organize my own household, finances, health and writing. With my permission, it reads my own Google account (Gmail, Calendar, Drive, Docs and Sheets). It can save email drafts and create calendar events, and only does so when I ask. It is not offered to anyone else, and no one else's data is collected.
